Inventory Management System

Project Description

The Inventory Management System is a web-based application designed to help organisations manage their stock and supplier information. It helps users keep track of available items and prepare stock reports.

Technologies Used

- HTML5
- CSS3

Main Features

1. Dashboard
2. List of Stock
3. Add Item
4. Suppliers
5. Stock Reports

How to Access

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the "index.html" file using a web browser.

Project Structure

- "index.html" – Main page of the system.
- "style.css" – Styles the appearance of the system.
- "README.md" – Provides information about the project.
